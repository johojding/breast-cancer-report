# Data

## Dataset
This project uses the Wisconsin breast cancer dataset provided by scikit-learn

The dataset contains 569 observations and 30 numerical features derived from digitized images of breast masses. The associated target labels distinguish malignant from benign cases.

## Access
The dataset is loaded through 'sklearn.datasets.load_breast_cancer' and does not need to be stored manually in this directory.

## Data handling
Generated reports are stored in the project's reports/ directory. No raw dataset file is required in data/ for the current workflow.
